# ТЗ для Codex — «упаковка» Telegram-бота @azkarnurtechbot

Проект «Азкар» (Telegram Mini App для азкаров) уже работает: https://azkar.nurtech.dev,
бот **@azkarnurtechbot**. Твоя задача — сделать бота красивым и понятным: брендинг, описание
проекта на стартовом экране, приветственное сообщение с картинкой, команды и картинки.

## Контекст / что НЕ трогать

- Код бота: `bot/server.js` (express-статик + бот на polling + напоминания по времени намаза).
- Токен — в локальном `bot/.env` (в git его НЕТ). Тебе он нужен только если запускаешь разовый
  скрипт; но лучше все вызовы Bot API добавить в **startup бота в server.js** — тогда они
  применятся сами при следующем деплое.
- НЕ трогай логику напоминаний/намаза/времён, эндпоинты `/api/*`, счётчик, тексты азкаров.
- НЕ коммить токен. Деплой делает владелец (ты только меняешь код + генеришь картинки → коммит+пуш,
  потом пишешь «готово», владелец передеплоит).
- Dockerfile копирует `bot/` целиком, так что файлы из `bot/assets/` попадут в контейнер.

## ЗАДАЧА 1 — Брендинг бота через Bot API (в startup `bot/server.js`)

Добавь в блок запуска бота (там, где уже есть `setChatMenuButton`) вызовы Bot API. Оберни в
try/catch, чтобы не ронять бота. Тексты — ниже, на русском.

- `bot.setMyName('Азкар — поминания')`
- `bot.setMyShortDescription(...)` — до 120 символов (видно в профиле бота):
  > Утренние и вечерние поминания и азкары после намаза. Счётчик-тасбих, напоминания по времени намаза.
- `bot.setMyDescription(...)` — до 512 символов (текст на пустом экране ДО кнопки «Запустить»):
  > 🕌 Азкар — утренние и вечерние поминания и азкары после намаза из достоверной Сунны.
  >
  > • Читай список сверху вниз: арабский, транскрипция, перевод и источник
  > • Счётчик-тасбих — отмечай повторения касанием
  > • Напоминания приходят по времени твоего намаза (после Фаджра и Асра)
  > • Выбор мазхаба, светлая и тёмная тема
  >
  > Нажми «Запустить», чтобы открыть приложение.
- `bot.setMyCommands([...])`:
  - `{ command: 'start', description: 'Открыть приложение' }`
  - `{ command: 'help', description: 'Как пользоваться' }`

Проверь имена методов в библиотеке `node-telegram-bot-api` (setMyName/setMyDescription/
setMyShortDescription/setMyCommands есть). Если какого-то метода нет в версии — вызови
соответствующий Bot API метод напрямую через `bot._request`/`fetch` на
`https://api.telegram.org/bot<token>/setMyDescription` и т.п.

## ЗАДАЧА 2 — Красивое приветствие на /start (с картинкой)

Сейчас `/start` шлёт текст + инлайн-кнопку web_app. Сделай так, чтобы он слал **фото-баннер
с подписью** и той же кнопкой:

- Сгенерируй баннер `bot/assets/welcome.png` (1280×720), в стиле приложения:
  мягкий шалфейно-зелёный `#6FA58C` + тёплая бумага `#F5F3EC`, спокойный пейзаж рассвет/сумерки,
  по центру/сбоку — элегантная 8-конечная исламская звезда (khatam). Без людей/зданий мечети.
  На баннере допускается арабская каллиграфия «أذكار» или слово «Азкар» аккуратно — но лучше без
  текста, чтобы не конфликтовать с подписью.
- В обработчике `/start`: `bot.sendPhoto(chatId, welcomePath, { caption, parse_mode:'HTML', reply_markup: <та же inline-кнопка web_app> })`.
  Подпись (caption) — тёплое приветствие + краткое описание (можно взять из setMyDescription,
  сократив), с «Ассаляму алейкум 🌿». Сохрани существующую регистрацию подписчика.
- Добавь обработчик `/help` — короткий текст: как открыть приложение, как включить геолокацию для
  напоминаний по намазу, как выбрать мазхаб, что счётчик считает касанием. Тоже с кнопкой web_app.

## ЗАДАЧА 3 — Картинки для профиля бота (файлы для владельца)

Эти вещи Bot API поставить НЕ может — только BotFather вручную. Подготовь файлы, а владелец
загрузит их (см. Задачу 4):

- `bot/assets/avatar.png` — квадратный аватар бота 512×512: 8-конечная звезда (khatam)
  шалфейно-зелёная на тёплой кремовой подложке, минимализм, по центру. (Можно взять
  `miniapp/assets/icon.png` как основу, но перегенерируй чисто под аватар 512×512.)
- `bot/assets/demo.png` — демо-картинка для стартового экрана 640×360 (та же, что welcome, но
  в пропорции 16:9 под требования BotFather).

## ЗАДАЧА 4 — Инструкция владельцу (выведи в конце как чек-лист)

Что владелец сделает руками в @BotFather (Codex это автоматизировать не может):
1. `/setuserpic` → @azkarnurtechbot → загрузить `bot/assets/avatar.png` (аватар бота).
2. Edit Bot → Edit Description Picture → загрузить `bot/assets/demo.png` (картинка на стартовом
   экране над описанием).
3. (опц.) проверить, что имя/описание/команды применились после деплоя.

## Финал

- Держи `bot/assets/` с картинками, `bot/server.js` — рабочим (проверь `node --check bot/server.js`).
- `git add -A && git commit -m "feat(azkar): брендинг бота + приветствие с баннером" && git push`
- **НЕ деплой.** Напиши владельцу: «Бот упакован, картинки в bot/assets/ — передеплой и загрузи
  avatar.png/demo.png в BotFather». Владелец передеплоит и загрузит картинки.
