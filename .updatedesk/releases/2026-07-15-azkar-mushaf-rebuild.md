Notes for editor:
- What changed: режим «Страница» переведён с SVG-картинок QUL (+HTML-оверлей таджвида +scroll-snap карусель) на чистый HTML с пофайловыми шрифтами QCF. Кегль считается CSS-формулой от размеров контейнера (container queries), точная ширина строки берётся из метрик шрифта через canvas — без JS-измерений после вставки DOM, поэтому исчез двухпроходный рендер, дававший дёрганье. Листание — колода из трёх постоянных панелей на transform, DOM не пересобирается.
- Where to verify: Коран → режим «Страница» → листать свайпом; проверить стр. 1, 2, 207, 582, 604.
- Risks: шрифт страницы ждётся перед показом (иначе PUA-глифы пустые); при отсутствии сети и пустом кэше страница не отрисуется — для офлайна есть «Скачать мусхаф» в настройках.
