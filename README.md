# Азкар — утренние и вечерние поминания

Telegram-приложение для чтения азкаров (утро / вечер / после намаза) с напоминаниями
и счётчиками-тасбих. Делается как **кейс-витрина** для курса
[AI Product Engineer](https://aiengineer.nurtech.dev).

## Что это

- **Бот** — присылает напоминания утром (после рассвета) и вечером (после ʿасра).
- **Mini App** — интерфейс чтения: выбор сессии → список зикров сверху вниз →
  счётчики повторений (тасбих) → отметка выполнения.

## UX

Просто, как в оригинале-референсе, но дизайн на порядок лучше:

1. **Дом** — аят-цитата, streak, три карточки сессий (Утро / Вечер / После намаза).
2. **Чтение** — вертикальный список карточек-зикров: арабский, транскрипция,
   перевод, источник, аудио, **счётчик-тасбих**.
3. **Настройки** — тема (свет/тьма), размер арабского, время напоминаний, тумблеры.

## Дизайн

- Мягкая палитра: шалфейно-зелёный `#6FA58C`, тёплая бумага `#F5F3EC`.
- Собирается через **Claude Design** (claude.ai/design) → дизайн-система.
- Актуальный прототип: [`design/prototype.html`](design/prototype.html).

## Контент (источник правды)

Тексты азкаров — из книги шейха **Мухаммада ибн Саида Расляна**
«أذكار الصباح والمساء من صحيح السنة المطهرة» → [`content/raslan-source.pdf`](content/raslan-source.pdf).
Каждый зикр — с источником (Бухари / Муслим / …) и степенью достоверности.

⚠️ Раздел «после намаза» в книге Расляна отсутствует — берётся из достоверной Сунны
(Сахих Муслим и др.).
